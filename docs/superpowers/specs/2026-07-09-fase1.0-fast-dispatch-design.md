# Fase 1.0 — Fast-Dispatch (Puro Testo) — Design

> Roadmap: `docs/PIANO-IMPLEMENTAZIONE.md` §Fase 1 (Pipeline a Triplo Binario), step 1.0.
> Regole: `docs/piano_implementazione/00_regole_procedure.md` (MLX/Watchdog, standard codice).

## Obiettivo

Micro-step di classificazione all'ingresso della pipeline di ingestion: per ogni
pagina di un PDF decidere **una** rotta ed estrarre il testo al volo solo dove la
pagina è **born-digital e solo-testo**, bypassando completamente i modelli pesanti
(PixelRAG 1.1, DeepSeek-OCR 1.2) e risparmiando compute/RAM (PyMuPDF puro).

Si ferma all'**interfaccia di routing**: non chunka, non embedda, non chiama modelli.

## Principio Fail-Closed

Il modulo **rifiuta di inghiottire gli errori**. File corrotti o protetti da
password → eccezione tipizzata rilanciata + log strutturato. Nessun crash
silenzioso, nessun risultato-con-errore mascherato: il fallimento è rumoroso ed
esplicito. È responsabilità del chiamante batch (worker/watchdog) avvolgere la
chiamata in try/except per non interrompere il ciclo massivo.

## Riuso: classificatore P2.5

Il dispatch **non reinventa euristiche**. Consuma `src/ingestion/page_classifier.py`
(`page_features()` + `classify()`), già calibrato e testato sul corpus reale.
Zero soglie nuove. La decisione born-digital-solo-testo è una lettura pura di
`PageClass`:

```
FAST_TEXT  ⟺  pc.label == "testuale"  AND  not pc.dual
              AND not pc.no_text_layer  AND not pc.low_content
altrimenti →  HEAVY
```

- `no_text_layer` esclude le scansioni mute → **non** born-digital.
- `dual` / `label == "grafica"` escludono immagini/tabelle rasterizzate.
- `low_content` esclude le pagine quasi vuote (nulla da estrarre al volo).

## Contratto dati

```python
class Route(Enum):
    FAST_TEXT = "fast_text"   # born-digital solo-testo → testo estratto qui
    HEAVY     = "heavy"       # → binari 1.1 (PixelRAG) + 1.2 (DeepSeek-OCR)

@dataclass(frozen=True)
class PageDispatch:
    page: int                 # 1-based
    route: Route
    text: str | None          # valorizzato SOLO se FAST_TEXT
    reason: str               # auditabile (da PageClass.reason)
    features: dict            # feature PyMuPDF (audit)

@dataclass(frozen=True)
class DocumentDispatch:
    filepath: str
    born_digital: bool        # almeno una pagina ha text-layer estraibile
    n_pages: int
    pages: list[PageDispatch]
    fast_pages: int
    heavy_pages: int
```

## API

- `route_for(pc: PageClass) -> Route` — funzione **pura**, mappa classe→rotta.
  Unit-testabile senza PDF reali.
- `dispatch_pdf(filepath, *, extract_text=True) -> DocumentDispatch` — core
  sincrono. `extract_text=False` classifica senza estrarre (dry-run rapido).
- `dispatch_pdf_async(filepath, *, extract_text=True)` — wrapper `asyncio.to_thread`
  per l'event loop futuro (Chainlit/FastAPI): fitz è una lib C bloccante
  CPU-bound, nessun finto-async.

## Estrazione fast-path

Solo pagine FAST_TEXT: `page.get_text("text")` (istantaneo). Pagine HEAVY →
`text=None`: flaggate, non processate.

## Gestione eccezioni

```python
class FastDispatchError(Exception): ...
class EncryptedPdfError(FastDispatchError): ...   # doc.needs_pass
class CorruptPdfError(FastDispatchError): ...     # apertura fitz fallita / file dati
```

Log strutturato al punto di fallimento (filepath, tipo errore), **poi** rilancio.
A fine documento: log informativo con conteggi rotta.

## Test (`tests/test_fast_dispatch.py`)

PDF sintetici generati con fitz (ermetici, deterministici):
- pagina solo-testo → FAST_TEXT + testo estratto;
- pagina con immagine / disegno vettoriale denso → HEAVY, `text is None`;
- PDF misto → split per-pagina corretto, `born_digital=True`;
- `extract_text=False` → nessuna estrazione anche sulle FAST_TEXT;
- PDF cifrato → `EncryptedPdfError`;
- file corrotto / inesistente → `CorruptPdfError`.
- unit puri su `route_for()` per ogni variante di `PageClass`.

## Fuori scopo (esplicito)

PixelRAG, DeepSeek-OCR, chunking, embedding, DB. Il dispatch termina consegnando
`DocumentDispatch`; i binari 1.1/1.2 sono passi successivi della Fase 1.
